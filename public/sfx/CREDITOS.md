# Créditos dos efeitos sonoros

Os arquivos desta pasta foram copiados (só renomeados) do projeto **Conquest**
— https://github.com/hoffspot/conquest — distribuído sob a licença Apache 2.0.

Segundo o README daquele projeto, os sons foram montados a partir de gravações
**CC0 ou de domínio público**: Kenney (RPG Audio, Impact Sounds, Casino Audio — https://kenney.nl),
Jan Schupke e Still North Media (OpenGameArt), artisticdude (RPG Sound Pack), rubberduck
(80 CC0 RPG SFX), lentikula (Basic Spell Impacts), Versilian Community Sample Library,
National Park Service e diversos autores do Freesound (lista completa no README do Conquest).
